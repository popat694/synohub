# SynoHub

SynoHub is a React + Tailwind admin dashboard scaffold based on the TailAdmin theme.

## Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS v4
- TailAdmin-inspired dashboard layout and UI patterns

## What is included

- Responsive sidebar shell
- Dashboard landing page
- Auth pages
- Tables, charts, forms, and UI element pages
- Dark-mode ready styling

## Getting started

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` - start the dev server
- `npm run build` - type-check and build for production
- `npm run lint` - run ESLint
- `npm run preview` - preview the production build
