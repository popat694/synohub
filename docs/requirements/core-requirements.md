# Core Requirements

## Product goal
Build SynoHub as a React admin dashboard starter that uses Tailwind CSS and the TailAdmin visual system.

## Intended users
- Product and operations teams that need an admin interface
- Engineers who will extend the dashboard into a real internal product

## Primary workflows
- Navigate between dashboard sections from a persistent shell
- Review summary metrics, trends, and recent activity
- Use auth pages for sign-in and sign-up entry points
- Access reusable examples for forms, tables, charts, and UI states

## Constraints
- Must remain lightweight enough to start development quickly
- Must support responsive layouts and dark mode
- Must stay easy to extend without rewriting the scaffold

## Non-goals for the scaffold
- No backend implementation yet
- No real authentication or API integration yet
- No complex domain workflows until the product definition is expanded
